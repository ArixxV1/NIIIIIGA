## StudyHub — образовательная платформа для студентов (Django)

Полноценное Django-веб-приложение без REST/React: Django Templates + Bootstrap 5 (CDN) + SQLite.

### Возможности
- Главная страница со списком предметов (карточки)
- Страница предмета со списком тем
- Страница темы с описанием, кнопкой «Материалы» и «Пройти тест», если тест есть
- Прохождение теста (A/B/C/D) и страница результата с подсветкой ошибок
- Регистрация/вход пользователей (сохранение прогресса и личный кабинет)
- Личный кабинет: прогресс по темам и история попыток
- Контент (предметы/темы/тесты/вопросы/материалы) создаёт **только администратор** через Django Admin
- После миграций в базу автоматически добавляются примерные данные (предметы/темы/материалы/несколько тестов)

### URL
- Главная: `/`
- Предмет: `/subject/<id>/`
- Тема: `/topic/<id>/`
- Материалы темы: `/topic/<id>/materials/`
- Тест: `/test/<id>/`
- Профиль: `/profile/`
- Вход: `/accounts/login/`
- Регистрация: `/accounts/register/`
- Админка: `/admin/`

### Быстрый старт

```bash
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

После запуска откройте сайт: `http://127.0.0.1:8000/`
